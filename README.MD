DCortinarius is a simple tool written in rust to control the RGB fan lights and fan speed of framework desktops running Linux!

Originally forked from: https://github.com/manimohans/framework_fan_rgb

DCortinarius is vibe coded but actually functions very well

The name is a bit of wordplay "The Cortinarius" as **Cortinarius** is a genus of mushrooms with rusty brown spores 

You can buy framework desktops here: https://frame.work/desktop
